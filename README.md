# Claude 資産運用シミュレーション(テンプレート)

Claude に株の運用を任せて、成績を確かめるための道具一式です。**実際のお金は動きません。**
仮想の資金(初期値は30万円)で売買の練習をして、「Claude の判断は、全世界株式(オルカン相当)を買って放置するより良いか」を長い期間かけて比べます。

プログラミングの経験がなくても使えます。手順は [docs/はじめかた.md](docs/はじめかた.md) に、画面の操作まで書いてあります。

## できること

- Claude が毎日（または好きな頻度で）ニュースや決算を調べて、買う・売る・見送るを判断する
- 判断の理由を日報（`data/journal/`）に毎回書く
- 成績を [REPORT.md](REPORT.md) にまとめる（Claude の運用と、オルカン放置との比較）
- 売買の条件（手数料、取引できる市場、1回に買える額など）を、現実の証券会社に近づけてある

## 3分でわかる全体像

| 役 | 誰が | 何をする |
|---|---|---|
| 判断 | Claude | 何を、なぜ、いつ買うかを決める |
| ルールの番人 | `sim.py` | 残高の計算、約定、上限ルール、記録。Claude は勝手にルールを破れない |
| 見張り・最終判断 | あなた | 日報と成績を読む。ルールを変える。実際の売買をするかどうかを決める |

## 読む順番

1. [docs/はじめかた.md](docs/はじめかた.md) — 準備から最初の1回まで（最初に読む）
2. [docs/毎日の使い方.md](docs/毎日の使い方.md) — 成績と日報の読み方、自動で動かす方法
3. [docs/設定とカスタマイズ.md](docs/設定とカスタマイズ.md) — 資金額や投資の方針を自分用に変える
4. [docs/困ったとき.md](docs/困ったとき.md) — エラーが出たとき、よくある質問

## ファイルの中身

| ファイル | 内容 | 触ってよいか |
|---|---|---|
| `config.json` | 資金額、上限、手数料などの数字 | **変えてよい**（変え方は設定の文書へ） |
| `CLAUDE.md` | 投資の方針と、Claude への毎回の手順 | **変えてよい**（あなたの考えに合わせる） |
| `sim.py` | シミュレーター本体 | 触らない |
| `REPORT.md` | 最新の成績（運用を始めると自動で作られる） | 読むだけ |
| `data/journal/` | 日報（日付ごと） | 読むだけ |
| `data/watchlist.json` | 監視銘柄と、買う条件・売る条件 | Claude が更新する |
| `data/state.json` など | 残高や注文の記録（運用を始めると作られる） | **手で編集しない** |
| `run_daily.ps1` / `run_daily.sh` | 1回分の運用を自動で実行するスクリプト（Windows / Mac・Linux） | 触らない |
| `register_task.ps1` | Windows で毎朝自動実行するように登録する | 一度実行するだけ |
| `docs/` | 使い方の文書 | 読む |

## 注意

これは学習と検証のためのシミュレーションで、投資の助言ではありません。
シミュレーションの成績が良くても、実際の取引で同じ結果になるとは限りません。実際のお金で売買するときは、自分で判断し、自分の責任で行ってください。
