# 設定とカスタマイズ

**変えてよい場所は2つです。数字は `config.json`、投資の考え方は `CLAUDE.md`。** それ以外（`sim.py`、`data/` の記録ファイル）は触りません。

## 1. 数字を変える（config.json）

`config.json` をメモ帳などで開き、数字を書き換えて保存します。カンマ（`,`）や引用符（`"`）を消さないように気をつけてください。変更したら、`python sim.py rules` で反映されたか確かめます。

| 項目 | 意味 | 初期値 | 変え方の例 |
|---|---|---:|---|
| `initial_jpy` | 仮想資金（円）。**運用を始める前に決める** | 300000 | 100万円なら `1000000` |
| `benchmark` | 比べる相手（銘柄コード） | `"ACWI"` | 日本株なら `"1306.T"`（TOPIX 連動 ETF）など |
| `max_position_pct` | 1銘柄に入れてよい上限（総資産に対する%） | 100 | 分散を強制するなら `30` |
| `max_orders_per_window` | 期間内に出せる注文の数 | 3 | 慎重にするなら `2` |
| `order_window_days` | 上の注文数を数える期間（日） | 6 | |
| `min_reason_chars` | 注文の理由の最低文字数 | 20 | |
| `slippage_pct` | 約定価格が不利な方にずれる幅（%） | 0.1 | |
| `halt_drawdown_pct` | 最高値からこれだけ下がったら新規買いを止める（%） | 30 | もっと早く止めるなら `20` |
| `order_expiry_days` | 成立しない注文を捨てるまでの日数 | 10 | |
| `markets` | 売買できる市場と、売買単位、片道コスト | 楽天証券の条件 | 下を見る |

### 市場とコストを変える（markets）

`markets` は、銘柄コードの末尾ごとに「市場名」「売買単位（株）」「片道コスト（%）」を決めます。

```
".T": {"name": "日本", "lot": 1, "cost_pct": 0.2}
```

- 末尾が `""`（空）のものが米国株、`".T"` が東京、`".HK"` が香港です。
- 使っている証券会社の手数料に合わせて `cost_pct` を変えると、成績が現実に近づきます。例: 米国株の手数料と為替コストが合計で0.9%なら `0.9`。
- 取引しない市場の行は、消せば買えなくなります。

## 2. 投資の考え方を変える（CLAUDE.md）

`CLAUDE.md` は、Claude が毎回読む「指示書」です。初期の中身は次の方針です。

- **ハイプサイクル**（＝新しい技術への期待が膨らみ、しぼみ、落ち着くまでの流れ）で、期待が冷めたのに実需が伸びている銘柄を狙う
- **国策・技術覇権**（半導体、電力網、防衛など、政府が後押しする分野）を優先する
- **つるはしとシャベル**（ブームの勝者ではなく、誰が勝っても必要になる供給者）を買う
- 既定は「何もしない」。売買は回数を減らし、1回を大きくする

これを自分の考えに書き換えられます。たとえば:

- 「配当が出る大型株だけを買う」と書く
- 「テーマ投資はせず、インデックス ETF だけを買う」と書く
- 「リスクを抑える。1銘柄は総資産の20%まで」と書く（`config.json` の `max_position_pct` も合わせる）

書き換えるときの注意:

- **「〜のときだけ買う」「〜は買わない」のように、はっきり書く。** あいまいだと Claude の判断がぶれます。
- 「ハードルール」の節は、`sim.py` が強制するルールの説明です。数字を変えたいときは、`CLAUDE.md` ではなく `config.json` を変えます。
- 「毎回の手順」と「禁止事項」の節は、変えないでください。記録が壊れたり、Claude がルールを回避したりする原因になります。

## 3. 監視銘柄のメモ（data/watchlist.json）

Claude が毎回更新する、銘柄ごとのメモです。あなたが書く必要はありません。あなたが「この銘柄も見てほしい」と思ったら、Claude に話しかけるときに伝えれば、Claude が書き足します。

1銘柄ぶんの書き方の例:

```
"NVDA": {
  "name": "NVIDIA",
  "status": "監視中（未保有）",
  "principles": ["国策・技術覇権", "つるはしとシャベル"],
  "hype_stage": "過度な期待のピーク（根拠を書く）",
  "thesis": "買う理由",
  "downside": "外れたらどうなるか",
  "buy_more_if": "買い増す条件",
  "sell_if": "売る条件（買った理由が崩れたと判断する具体的な条件）",
  "last_updated": "2026-01-01"
}
```

## 5. Claude に許可する操作を変える（上級者向け）

`.claude/settings.json` に、Claude が確認なしにやってよい操作（`allow`）と、やってはいけない操作（`deny`）が書いてあります。初期設定では、価格を調べる・Web を検索する・日報と監視銘柄メモを書く・`sim.py` を使う、記録の保存（`git add` / `git commit` / `git push origin HEAD:main`）が許可されています。強制 push と `git reset --hard` は禁止です。`sim.py` や記録ファイルを書き換える操作と、`resume`（新規買いの停止解除）は禁止です。**この設定は、お金のルールを守る柵なので、理由がなければ変えないでください。**
