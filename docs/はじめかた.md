# はじめかた

**この文書をひととおり進めると、仮想のお金で Claude が運用を始められます。** 所要時間は、準備が済んでいれば30分ほどです。
すべての操作でお金はかかりません（ただし Claude の利用料は別です。「3. Claude Code を入れる」を見てください）。

## 先に知っておくこと

- 実際の証券口座にはつながりません。売買はすべてコンピューター上の「ごっこ」です。
- 株価は Yahoo Finance の無料データを使います。インターネットにつながっている必要があります。
- 操作は「ターミナル」という黒い画面に、文字を打ち込んで行います。この文書のコマンド（`python sim.py init` のような文字列）は、そのままコピーして貼り付ければ動きます。

> **ターミナルの開き方**
> - Windows: フォルダ（この一式を置いた場所）を開き、アドレスバーに `powershell` と打って Enter を押す
> - Mac: Finder でフォルダを右クリックし、「フォルダに新規ターミナル」を選ぶ

## 1. 必要なものを入れる

3つ入れます。すでに入っているものは飛ばしてください。

| 道具 | 何に使うか | 入れ方 |
|---|---|---|
| Python | `sim.py`（ルールの番人）を動かす | https://www.python.org/downloads/ から最新版を入れる。Windows では、インストール画面の **「Add python.exe to PATH」にチェックを入れる** |
| Git | 記録の履歴を残す | https://git-scm.com/downloads から入れる。設定は初期のままでよい |
| Claude Code | 運用を判断する Claude 本体 | 次の「3」を見る |

入ったかどうかは、ターミナルに次を打って確かめます。バージョン番号が出れば成功です。

```
python --version
git --version
```

Mac では `python` の代わりに `python3` と打ちます（この文書のほかの `python` も同じです）。

## 2. この一式を自分の場所にコピーする

GitHub のこのページで **「Use this template」→「Create a new repository」** を押し、自分用のコピーを作ります（非公開の「Private」をおすすめします。運用の記録があなたのものになり、人に見られません）。

次に、コピーしたものを自分のパソコンに取り込みます。ターミナルで、置きたい場所に移動してから次を打ちます（`あなたの名前/リポジトリ名` はコピーしたページのものに置き換えます）。

```
git clone https://github.com/あなたの名前/リポジトリ名.git
cd リポジトリ名
```

> GitHub を使わず、フォルダごとコピーして使うこともできます。その場合は、フォルダの中で `git init` と打ってから進めてください。記録はそのパソコンの中だけに残ります。

## 3. Claude Code を入れる

Claude Code は、ターミナルで Claude を動かす公式の道具です。入れ方は更新されることがあるので、公式の案内（https://docs.claude.com/ で「Claude Code」を探す）に従ってください。
入れ終わったら、ターミナルで `claude` と打ちます。初回はログインの画面が出るので、Claude のアカウントでログインします。

費用: Claude Code の利用には、Claude の有料プラン（Pro / Max）か、API の利用料がかかります。1回の運用で調査を何度も行うため、使う量は少なくありません。無料のままでは動かないことがあります。

## 4. 好みを決める（飛ばしてもよい）

- **仮想資金の額を変えたい** → `config.json` の `initial_jpy` を書き換える（初期値は 300000 ＝30万円）。**運用を始める前（次の手順の前）に変える。** 始めたあとに変えても反映されません。
- **投資の方針を変えたい** → `CLAUDE.md` の「投資の原則」を書き換える。

詳しくは [設定とカスタマイズ](設定とカスタマイズ.md) を見てください。まずは初期値のままで試すのがおすすめです。

## 5. 運用を始める（初期化）

ルールを確かめてから、運用を始めます。

```
python sim.py rules
python sim.py init
```

- `rules` は、いまのルール（資金、上限、手数料）を表示します。
- `init` は、仮想資金で運用を始める操作です。**一度だけ**実行します。「仮想資金 300,000 円で開始しました」と出れば成功です。

`init` を実行すると、`data/` フォルダの中に記録のファイルが作られます。

## 6. 最初の1回を実行する

```
claude
```

Claude が起動したら、次のように話しかけます。

> CLAUDE.md の「毎回の手順」に従って、今日の運用を1回分実行してください。

Claude が、最新のニュースを調べ、価格を確かめ、買うか見送るかを決めて、日報を書きます。5〜15分ほどかかります。途中で「このコマンドを実行してよいですか？」と聞かれたら、内容を読んで許可してください（`.claude/settings.json` に書いたものは、聞かれずに実行されます）。

終わったら、次の2つを開いて読みます。

- `REPORT.md` — 現在の成績
- `data/journal/` の中の、今日の日付のファイル — Claude が何を見て、どう判断したか

最初の回は、何も買わずに「見送り」になることもよくあります。**「何もしない」が初期の方針**なので、それで正常です。

## 7. 毎日自動で動かす

毎回自分で話しかけなくても、決まった時間に自動で動かせます。方法は [毎日の使い方](毎日の使い方.md) の「自動で動かす」に書いてあります。
