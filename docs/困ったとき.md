# 困ったとき

## エラー・メッセージ別

| 出たもの | 原因 | 直し方 |
|---|---|---|
| `python は認識されません` / `command not found: python` | Python が入っていない、または PATH（＝探す場所）に入っていない | Python を入れ直し、「Add python.exe to PATH」にチェックを入れる。Mac では `python3` と打つ |
| `未初期化です。先に python sim.py init を実行してください。` | 運用をまだ始めていない | `python sim.py init` を一度だけ実行する |
| `すでに初期化済みです。` | `init` を2回実行した | 何もしなくてよい。最初からやり直すなら [毎日の使い方](毎日の使い方.md) の「最初からやり直す」へ |
| `config.json を読めません` | `config.json` の書き方が壊れている（カンマ・引用符の抜け） | 直前に変えた行を見直す。直せなければ、Git から元に戻す（`git checkout config.json`） |
| `注文拒否: 直近6日間の注文数が上限(3件)に達しています` | 注文の上限に達した | 正常な動きです。数日待つ。上限は `config.json` で変えられる |
| `注文拒否: 現金不足です` | 現金が足りない | 株数を減らす。Claude が自分で判断し直します |
| `注文拒否: ... 取扱市場外です` | その銘柄の市場が `config.json` の `markets` にない | 米国上場の ADR（＝海外企業の株を米国で買えるようにしたもの）で買えるか探す。または `markets` に足す |
| `注文拒否: 停止中のため新規買いはできません` | 資産が最高値から大きく下がり、自動停止した | 日報で理由を読み、納得してから `python sim.py resume`（人間だけが実行する） |
| `取得失敗` / 価格が取れない | 銘柄コードの間違い、またはネットが切れている、Yahoo Finance が一時的に不調 | 銘柄コードを見直す（東京は `7203.T` のように `.T` を付ける）。少し待つ |
| `claude` が見つからない | Claude Code が入っていない、または PATH に入っていない | [はじめかた](はじめかた.md) の「3」をやり直す |
| 自動実行が動かない | 下の「自動実行が動かないとき」を見る | |

## 自動実行が動かないとき

1. `logs/` フォルダの、今日の日付のファイルを開く。何が起きたかが書いてあります。
2. ファイルが無い → タスクが登録されていない、またはパソコンの電源が入っていない。`register_task.ps1` をもう一度実行する。
3. `claude` が見つからないと書いてある → `run_daily.ps1` の中の、`$env:Path = ...` の行の `#` を消し、Claude Code が入っている場所を書く。場所は、ターミナルで `(Get-Command claude).Source` と打つと出る。
4. 手で `.\run_daily.ps1` を実行して、動くか確かめる。

## よくある質問

**Q. 実際のお金は動きますか？**
動きません。仮想の資金での練習です。証券口座にもつながりません。

**Q. 1回の運用にいくらかかりますか？**
運用そのものは無料です。Claude Code の利用料だけがかかります。1回で調査を何度もするので、毎日動かすと使う量が多くなります。週1回から始めるのがおすすめです。

**Q. 毎日動かすべきですか？**
いいえ。長期保有が前提で、「既定は何もしない」方針なので、週1回でも十分です。

**Q. Claude が全然買わないのですが、壊れていますか？**
壊れていません。初期の方針は「原則に照らして明確な理由があるときだけ買う」です。日報を読むと、なぜ見送ったかが書いてあります。もっと積極的にしたければ、`CLAUDE.md` の「既定は何もしない」の部分を書き換えます。

**Q. 成績が負けていますが、やめたほうがよいですか？**
数週間の差は偶然のことが多いです。半年から数年の長さで、オルカン放置と比べてください。そのうえで、負け続ける理由が日報から読み取れるなら、`CLAUDE.md` の方針を見直します。

**Q. 日本株だけにしたい／米国株だけにしたい**
`config.json` の `markets` から、使わない市場の行を消します。そのうえで、`CLAUDE.md` にも「日本株だけを買う」と書いておくと、Claude が最初から候補を絞ります。

**Q. 記録（日報や成績）を消してしまいました**
Git で戻せます。ターミナルで `git checkout -- data REPORT.md` を打つと、最後にコミットした状態に戻ります。コミットしていない分は戻せません。

**Q. 他の人と共有していいですか？**
記録と日報には、あなたの運用の中身が入っています。リポジトリは Private（非公開）にしておくのをおすすめします。

**Q. 実際の売買に使えますか？**
投資の助言ではありません。シミュレーションの結果は、将来の成績を保証しません。実際に売買するときは、自分で判断し、自分の責任で行ってください。
